## Roadmap created by ChatGPT for optimised and organised learning rather than randomised learning.

PerfOracle V1 — 45-Day Plan

Daily: 60–120 min learning + 2–4 hrs implementing.
Rule: never watch the next day's material until you've completed that day's implementation.
