# Quant Research Engine

A quantitative research and backtesting framework combining Python research workflows with performance-oriented C++ components.

## Features

- Historical data processing
- Event-driven backtesting
- Strategy framework
- Portfolio simulation
- Transaction-cost modeling
- Slippage modeling
- Statistical analysis
- Performance evaluation
- C++ acceleration

## Tech Stack

### Python
- NumPy
- Pandas
- SciPy
- Matplotlib

### C++
- C++20
- CMake

## Architecture

```text
Historical Data
      ↓
Data Processing
